# TPI_colonia_gatos_web
Trabajo practico web

Este proyecto depende de la aplicacion de escritorio "TPI_colonia_gatos".

Tecnologías usadas:
* **Backend:** Java EE, Servlets, JPA (EclipseLink).
* **Frontend:** JSP, Bootstrap 5 (Estilo Cápsula).
* **Base de datos:** MySQL.
* **Gestor de Dependencias:** Maven.

Cómo ejecutar:
1. Clonar el repositorio.
2. Configurar la base de datos en `persistence.xml`.
3. Ejecutar en Apache Tomcat 9+.
